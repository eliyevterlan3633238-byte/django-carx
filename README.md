# Çarx

Çarx layihəsi üçün istifadəçi interfeysi.

## Quraşdırma (Installation)

1. Repozitoriyanı klonlayın:
   ```bash
   git clone https://github.com/ISTIFADECI/REPO-ADI.git
   ```

2. Layihə qovluğuna daxil olun:
   ```bash
   cd Çarx
   ```

3. Virtual mühiti aktivləşdirin:
   - Windows üçün:
     ```bash
     projectvenv\Scripts\activate
     ```

4. Tələb olunan paketləri quraşdırın:
   ```bash
   pip install -r requirements.txt
   ```

## İşə salma (Usage)

Layihənin əsas səhifəsini (index.html) brauzerdə aça bilərsiniz.
